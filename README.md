StegX is a futuristic, AI-powered 3D web application that performs universal steganography across multiple file formats (Image, Audio, Video, and Text). Featuring advanced encryption algorithms, deep metadata analysis, quality metrics, and highly interactive 3D visualizations built on Three.js and Vite.

### ✨ Key Features
- **Universal Steganography:** Hide secrets within Images (LSB, DCT, DWT), Audio (Phase Coding, Echo Hiding), Video, and Text.
- **Advanced Encryption:** AES-128/192/256, RSA, ECC, ChaCha20, and Blowfish.
- **AI-Powered Analysis:** Capacity recommendations and stego-quality analysis (PSNR, SSIM).
- **Cyberpunk 3D UI:** Highly immersive Glassmorphism design with Three.js particle systems, binary rain, and dynamic neon glows.

### 🚀 Tech Stack
- **Frontend:** HTML5, Vanilla JavaScript, CSS3, Vite, Three.js, Chart.js.
- **Backend:** Python, FastAPI, SQLite, OpenCV, PyCryptodome, Numpy, Scipy.
- **Deployment:** Vercel (Frontend SPA) + Render (FastAPI Backend).
